# 负面提示与故障排查

负面提示的作用是保护镜头目标，不是列出所有可能错误。每次选择 3–8 项。

## 人物

```text
避免身份漂移、脸部突然变化、多余手指、肢体融合、服装颜色改变、背景人物复制。
```

## 物体与物理

```text
避免道具凭空出现或消失、抓握点滑动、液体逆流、接触面穿透、影子方向错误、反射与主体不同步。
```

## 镜头

```text
避免无原因变焦、镜头穿过实体、随机环绕、地平线漂移、焦点抽动、突然切换焦段、无原因慢动作。
```

## 画面与文字

```text
避免文字乱码、标志变形、重复纹理、边缘融化、过度锐化、塑料皮肤、无来源镜头光晕。
```

## 连续性

```text
人物数量不变；左右手持物不交换；门的开合状态连续；主体始终向画面左侧移动；天气和光源方向不变。
```

## 症状 → 修复

| 症状 | 先改什么 | 不要做什么 |
|---|---|---|
| 人脸漂移 | 减少人物数量，保留 2–3 个身份锚点 | 加入更多五官形容词 |
| 动作混乱 | 只留一个动作链，写清结束状态 | 增加更多动作 |
| 镜头乱飞 | 固定机位或只留一种运镜 | 堆叠稳定器、无人机、环绕等词 |
| 画面很 AI | 明确素材来源、材质和物理响应 | 继续添加“真实、8K、电影感” |
| 背景复制 | 降低背景人物密度，指定少量独立行为 | 笼统写“拥挤人群” |
| 图生视频变脸 | 降低头部转动和遮挡，先做小幅动作 | 同时大幅运镜和快速转身 |

如果负面提示越来越长，通常说明正向动作或镜头设计本身存在冲突，应返回主提示词修正。
