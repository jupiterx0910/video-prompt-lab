# 镜头语言词典

## 景别决定信息密度

| 景别 | 适合表达 | 常见错误 |
|---|---|---|
| 大远景 | 环境规模、主体与世界关系 | 主体动作写得过细 |
| 全景 | 完整肢体动作、走位 | 背景事件过多导致漂移 |
| 中景 | 人物行动与关系 | 同时要求宏大环境展示 |
| 近景 | 表情、手部和关键道具 | 大幅奔跑或复杂走位 |
| 特写 | 单一细节、触感、信息揭示 | 多主体互动 |

## 机位的叙事作用

- **眼平**：中性、观察感，适合纪实与对话。
- **低机位**：强化体量或压迫感；不要自动等同“英雄感”。
- **高机位**：展示路径、秩序或脆弱感。
- **肩后**：建立人物视线与目标，需锁定轴线。
- **主观视角**：强调手部、呼吸和视线转移，避免凭空看到拍摄者本人。
- **固定监控机位**：空间行为优先，不能同时要求电影式跟随。

## 焦段感

- **广角感（约 18–28mm）**：空间夸张、近大远小、运动速度感强。
- **自然视角（约 35–50mm）**：关系均衡，适合街拍和叙事。
- **中长焦感（约 70–135mm）**：空间压缩、背景靠近、主体隔离。
- **微距**：极浅景深和微小材质变化；不适合复杂走位。

焦段数字是沟通意图，不保证模型进行精确光学模拟。

## 运镜

| 运镜 | 使用条件 | 提示词要点 |
|---|---|---|
| 推近 | 信息或情绪逐步集中 | 起始景别、速度、结束位置 |
| 拉远 | 揭示环境或关系反转 | 最终出现的新信息 |
| 横移 | 跟随平行运动、展示层次 | 主体方向、前景遮挡、速度匹配 |
| 跟拍 | 持续观察主体动作 | 距离、机位高度、稳定程度 |
| 摇摄 | 从一个信息点转向另一个 | 起点、触发、终点，避免无目的扫景 |
| 环绕 | 展示物体体积或关系 | 角度范围，通常不必完整 360° |
| 手持 | 临场感和人的介入 | 呼吸式微动、跟随延迟，而非随机剧烈抖动 |
| 固定 | 让场内调度成为主角 | 入口、路径和离场点 |

## 一镜一意图

同一短镜头不要同时要求推近、拉远、环绕、升降和变焦。优先选择一个主要运动，必要时附加一个幅度很小的修正动作。
