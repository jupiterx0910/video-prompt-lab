# 视频提示词工程基础

## 1. 提示词不是文学描写

视频模型需要的是随时间变化的约束。一个有效提示词至少回答四个问题：初始状态是什么、什么触发了变化、变化如何发生、结束时留下什么结果。

把“一个悲伤的女孩站在车站”改成：

```text
女孩反复捏平已经被雨水浸软的车票；远处列车驶过却没有停靠，她抬头确认站牌，随后把行李箱拉回雨棚下。
```

后者没有直接说“悲伤”，但动作、道具和事件共同产生情绪。

## 2. 八层提示词结构

1. **任务层**：时长、比例、生成模式、用途。
2. **主体层**：数量、身份、固定外观、服装与道具。
3. **世界层**：地点、时间、天气、材质和空间关系。
4. **动作层**：触发、反应、结果与节奏。
5. **摄影层**：景别、机位、焦段感、运动和稳定方式。
6. **光色层**：光源、方向、软硬、曝光变化和色彩关系。
7. **声音层**：前景声、环境声、画外声和同步点。
8. **约束层**：连续性锁与针对性负面提示。

不是每次都要把八层写成长段。复杂镜头先完整设计，再按模型压缩。

## 3. 信息优先级

建议按以下顺序分配提示词预算：

```text
核心动作 > 主体一致性 > 空间与镜头 > 关键光线 > 次要细节 > 风格形容词
```

如果某项删除后不会改变视频结果，就应考虑删除。

## 4. 时间节拍

8–10 秒镜头通常适合三拍：

- **建立（0–2 秒）**：让观众理解主体和空间。
- **发展（2–6 秒）**：主要动作发生并遇到变化。
- **落点（6–10 秒）**：动作产生可见结果，镜头在稳定状态结束。

多镜头视频先写“镜头卡”，每张卡只承担一个叙事功能，再处理转场。

## 5. 抽象词翻译

| 抽象要求 | 可见/可听的表达 |
|---|---|
| 松弛 | 肩膀下沉、动作间有停顿、环境声留白、镜头不追得太紧 |
| 紧张 | 视线频繁越过镜头、呼吸变快、狭窄负空间、画外金属声逼近 |
| 温暖 | 低角度暖光穿过织物、皮肤反射柔和、近处生活声密度增加 |
| 孤独 | 主体占画面较小、远处持续机械声、无人回应的动作、长停顿 |
| 高级 | 材质控制、克制配色、精确反射、高光不过曝，而非简单写“奢华” |

## 6. 迭代而非重写

第一次生成后，先判断失败属于哪一层：

- 动作错：缩短动作链，强化触发与结果。
- 人物漂移：减少外观细节，增加固定锚点。
- 镜头乱：只保留一个主要运动，明确结束构图。
- 质感假：补充素材来源和物理细节，删除空泛风格词。
- 节奏平：调整时间节拍，不要盲目增加事件。

每轮只改一到两个变量，才能知道什么真正有效。
