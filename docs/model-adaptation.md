# 模型适配指南

> 产品版本变化很快。以下内容是稳健的写作策略，不代替各平台当前官方说明。

## 通用主稿

先保留一份与模型无关的“导演稿”，包含主体锁、动作因果、镜头、光线、声音、时间节拍和负面约束。模型版本只应是导演稿的编译结果。

## Seedance

- 用清晰时间顺序描述动作与镜头调度。
- 重要主体和动作放在前面，风格放在后面。
- 多镜头任务先拆成镜头卡，再明确切点和每镜头的叙事功能。
- 中文提示保持短句和动词密度，避免多层从句。

## Veo

- 将音频写成具体声源、距离和出现时刻。
- 对白要标注说话者，并控制在实际时长可容纳的范围内。
- 明确画内声与画外声，避免音乐、对白和环境声争夺重点。

## Sora

- 先建立世界状态和主体空间关系，再描述变化。
- 对复杂场景强化物理因果与摄影视角。
- 长镜头说明镜头为什么移动，以及最终停在哪里。

## Kling

- 图生视频优先写运动变化，不重复首帧里已经明确的静态信息。
- 锁定人物、道具和背景层次，避免同时要求大幅主体运动与复杂运镜。
- 从小幅动作开始迭代，再增加幅度。

## Runway

- 单次生成保持单一镜头意图和明确运动。
- 图生视频使用“主体怎么动、环境怎么响应、镜头怎么动”的顺序。
- 避免把多个剪辑镜头塞进一个本应连续的生成片段。

## 压缩方法

当模型或界面偏好短提示时，保留：

```text
主体锚点 + 核心动作因果 + 空间 + 一个镜头运动 + 关键光线变化 + 3 个负面约束
```

删除重复的风格词、不会影响画面的背景故事和互相近义的质量形容词。
