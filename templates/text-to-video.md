# 通用文生视频模板

```text
任务：[时长]，[比例]，[单镜头/多镜头]，[用途]。

主体锁：[人数、身份、年龄范围、轮廓、服装主色、一个识别特征、关键道具]。

世界状态：[具体地点]，[时间与天气]，[空间布局]，[2–3 个具有材质的环境细节]。

动作因果：[触发事件] → [主体如何反应] → [动作如何发展] → [最终可见结果]。

摄影：[起始景别]，[机位高度与角度]，[焦段感]，[一种主要运镜及速度]，[最终构图]，[稳定方式]。

光线与颜色：[主光源、方向、软硬、色温]；[动作过程中曝光/反射/阴影如何变化]；主色[ ]、辅助色[ ]、强调色[ ]。

时间节拍：
0–[ ]秒：[建立主体和空间]。
[ ]–[ ]秒：[主要动作及变化]。
[ ]–[结束]秒：[结果与结束状态]。

声音：[前景同步声]；[环境底噪]；第[ ]秒出现[叙事声音]，来自[方向/距离]。

连续性：锁定[人物/服装/道具状态/方向/空间/光源]。

避免：[3–8 个与本镜头高度相关的错误]。
```

精简版：

```text
[主体锚点]在[空间]因为[触发]完成[动作和结果]；[景别+机位+一种运镜]；[关键光线变化]；[同步声音]；保持[连续性锚点]；避免[核心错误]。
```
