# 图生视频模板

不要复述图片中已经存在的全部静态内容。先列出“保持不变”和“开始变化”。

```text
时长与比例：[ ]。

保持不变：[人物身份、面部、服装、构图核心、背景结构、光源方向]。

主体运动：[哪个部位先动]，[动作路径与幅度]，[动作的结束姿态]。

环境响应：[头发/衣料/液体/烟雾/反射/阴影如何被动作或风影响]。

摄影机：[固定 / 推近 / 横移 / 跟随]，[速度与幅度]。除这一运动外不改变焦段和机位。

时间节拍：
0–[ ]秒：[微小准备动作]；
[ ]–[ ]秒：[核心运动]；
[ ]–结束：[物理余韵和稳定结束状态]。

避免：首帧身份改变、背景重绘、额外人物或物体、肢体穿透、无原因变焦、循环动作、突然切镜。
```

建议先生成小幅动作版本；成功后再增加主体运动或镜头运动，避免一次同时放开三层运动。
