# 高质量案例库

下面的案例展示结构，不承诺复制后在所有模型上得到相同结果。生成时应根据平台限制和输入图像调整。

## 1. 雨夜便利店｜纪实手机视频

```text
10 秒，9:16。穿旧牛仔夹克的年轻外卖员在雨后凌晨的便利店门口整理被淋湿的纸袋。一辆车驶过溅起积水，他下意识用左臂护住纸袋，低头确认封口，再抬头看向街对面亮起的绿灯。腰部高度中景，约 35mm 自然视角，拍摄者后退一步跟随，跟随略慢半拍，不做环绕。便利店冷白灯从侧后方照亮雨滴，街道钠灯偏暖，车灯掠过时自动曝光短暂压暗。雨棚滴水、冰柜低鸣、轮胎压水声和纸袋摩擦声同步。锁定脸、夹克、纸袋破损位置和左手动作。避免多余手指、纸袋复原、路人复制、无原因慢动作、镜头穿过人物。
```

## 2. 早餐蒸汽｜食物微纪录

```text
8 秒，16:9。清晨小吃摊，摊主把刚出笼的包子夹进牛皮纸袋，热蒸汽先遮住他的手，随后被门口冷风吹向画面左侧。桌面高度近景，50mm 感，固定机位只做极小幅重新构图。窗外阴天柔光与摊内暖灯混合，纸袋吸收水汽后颜色局部变深。竹蒸笼轻响、夹子碰撞和远处自行车铃构成声音层次。包子数量、夹子位置和蒸汽方向保持连续。避免食物融合、夹子穿透、蒸汽逆风、过度油亮和广告式环绕。
```

## 3. 沙漠机器人｜写实科幻

```text
12 秒，2.39:1。一台膝部外壳磨损的测绘机器人站在黄昏沙丘脊线上，接收到远处信标后转动头部传感器，前腿试探性下压，沙面塌落迫使它后移半步并重新平衡。低机位全景，28mm 广角感，摄影机沿沙丘平行缓慢横移，最终停在机器人与远处信标形成对角线的位置。低角度橙色阳光勾出金属边缘，天空冷蓝；关节伺服声、细沙滑落声和远处低频信标同步。锁定四肢结构、磨损位置、信标方向和影子方向。避免多出机械腿、悬浮脚掌、沙粒逆重力、随机变形和突然变焦。
```

## 4. 一镜到底咖啡交接｜动作连续性

```text
9 秒，16:9。咖啡师从画面右侧把一杯贴有蓝色圆形标签的拿铁推向顾客；顾客右手接住杯子，左手把硬币放到木桌上，咖啡师收回托盘并点头。肩部高度中景，约 40mm，自始至终固定在柜台外侧，只缓慢推近 30 厘米。杯子始终只有一个，蓝色标签朝向摄影机，液面在交接时轻晃后稳定。杯底摩擦木桌、硬币落桌和咖啡机泄压声按动作顺序出现。避免左右手交换、杯子复制、标签变化、手指融合、轴线跳跃。
```

## 5. 山间民宿开窗｜氛围叙事

```text
10 秒，16:9。清晨，一名穿米白针织衫的住客推开木窗；潮湿冷空气进入房间，薄窗帘向内鼓起，桌上未熄灭的蜡烛火焰先倾斜后熄灭，她停下动作看向雾中的山谷。室内肩后中景，35mm 感，镜头缓慢靠近窗口但不越过人物。室内暖色残光与窗外蓝灰雾光交替，开窗后人物轮廓逐渐变冷。木窗摩擦、布料摆动、远处鸟鸣和蜡烛熄灭的轻响。锁定窗户开启方向、人物位置、蜡烛和窗帘运动因果。避免窗帘向错误方向、蜡烛复燃、雾进入室内形成烟柱、镜头穿过人物。
```

## 6. 耳机产品片｜单一卖点

```text
8 秒，1:1。深灰色头戴耳机放在带细微划痕的黑色石材台面，唯一卖点是柔软耳垫的回弹。戴棉质手套的手从上方缓慢按压左耳垫，泡棉均匀下陷，手移开后在两秒内平滑恢复原形。微距近景，85mm 感，固定机位，小幅焦点从指尖转移到恢复中的耳垫。狭长柔光在皮革纹理上形成连续高光，背景保持深灰。手套摩擦皮革和泡棉回弹的细微声音同步。锁定耳机结构、缝线、左右方向和表面反射。避免多余接口、Logo 乱码、耳机变形、手指异常、无原因旋转和漂浮。
```

## 7. 图生视频人像｜克制运动

```text
保持首帧人物面部、短发、黑色外套、背景窗框和侧光方向完全不变。人物先眨一次眼，视线从镜头缓慢移到窗外，呼吸使肩部产生极小起伏；窗边一缕头发被微风抬起后落回。摄影机固定，仅做几乎不可察觉的 2% 推近，焦段和构图不变。动作在 6 秒内完成并稳定结束。避免换脸、嘴部无意识运动、头部大幅旋转、背景重绘、窗框弯曲和循环眨眼。
```

## 8. 三镜头失物故事｜状态接续

```text
全局：红色旧围巾、冬日下午、车站冷白光、女孩深蓝大衣保持不变。
镜头1（4秒）：全景固定机位，女孩从左向右离开长椅，红围巾滑落在长椅右端；出口状态为女孩已出画、围巾留在右端。
镜头2（4秒）：长椅近景，入口保持围巾位置；清洁工从右侧进入，看到围巾后停下并拾起，出口为围巾在其左手。以远处列车广播做声音桥。
镜头3（5秒）：肩后中景，清洁工向站台左侧追去，女孩在远处回头；他举起左手中的红围巾，女孩停步。保持移动方向、围巾颜色和手持关系。避免围巾复制、位置跳变、人物换装和轴线反转。
```
