# Model Router

Route by required capability, not by a static quality ranking.

| Capability | Candidate models |
|---|---|
| Dialogue / native audio | Veo |
| Image-to-video | Kling, Runway |
| Strong continuity | Kling, Seedance |
| Multi-shot cinematic structure | Sora, Seedance |
| Product / commercial motion | Seedance, Kling |
| Creative visual exploration | Runway, Sora |

These are routing heuristics, not benchmark claims. If the user explicitly names a model, keep that model as the target and adapt the prompt to its strengths.
