# Failure Diagnosis

Diagnose before rewriting.

| Symptom | Likely layer | Minimal fix |
|---|---|---|
| Identity drift | Subject / continuity | strengthen identity anchor and persistent state |
| Object teleportation | State transition | define before/after state and causal action |
| Rubber motion | Physics / action | specify trigger, inertia, contact and consequence |
| Camera chaos | Camera | keep one dominant movement and remove conflicts |
| Temporal jump | Time | define beat order and duration |
| Audio mismatch | Audio / time | tie sound events to visible actions |
| Generic AI look | World / material | replace vague adjectives with observable physical cues |

Change the smallest number of variables needed to address the diagnosed failure.
