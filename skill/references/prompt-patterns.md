# Prompt Patterns

## Action causality

Use: `trigger → movement → reaction → result`.

## State continuity

Define the important state before and after an action. Repeat only continuity-critical facts.

## Camera economy

Specify framing first, then one dominant camera movement. Avoid stacking incompatible movements.

## Time beats

Express meaningful changes as ordered beats rather than a pile of simultaneous verbs.

## Physical grounding

Prefer observable material behavior: contact, inertia, deformation, reflection, shadow response, splash, dust, cloth movement.

## Negative constraints

Use negatives only when they target a plausible failure mode. Avoid generic lists of every possible artifact.
