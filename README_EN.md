# Video Prompt Lab

An engineering-oriented knowledge base for turning a rough idea into controllable, time-aware AI video prompts.

The repository covers prompt composition, camera language, motion continuity, lighting, sound, model adaptation, reusable templates, worked examples, and quality checks. Start with the [Chinese README](README.md), the universal [text-to-video template](templates/text-to-video.md), or the agent-compatible [SKILL.md](SKILL.md).

Core formula:

```text
intent + subject lock + world state + action causality + camera plan
+ lighting behavior + synchronized sound + continuity constraints + targeted negatives
```

This project was inspired by the “design believable source footage” idea in [zhouwei713/seedance-prompt](https://github.com/zhouwei713/seedance-prompt), but uses an independently written architecture and content.
